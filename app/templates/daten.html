📋 Rezept-Format für KI

Du kannst Rezepte mit einem KI-Chatbot (z.B. Claude) erstellen lassen und als JSON importieren. Teile dem Chatbot diese Vorlage mit: 

[
  {
    "name": "Rezeptname",
    "category": "Kategoriename",
    "description": "Kurze Beschreibung (optional)",
    "ingredients": [
      { "name": "Zutat 1", "amount": 200, "unit": "g" },
      { "name": "Zutat 2", "amount": 2,   "unit": "Stück" }
    ]
  }
]
✓ Kopiert
Import / Wiederherstellen

JSON-Datei wählen — eigene Rezepte (KI-Format), Export oder Backup. Der Typ wird automatisch erkannt.

🛍️ Bring! Einstellungen

Trage deine Bring!-Zugangsdaten ein. Danach erscheint in der Einkaufsliste die Option → Bring! zum direkten Übertragen.

⚠️ Backup wiederherstellen

Eine Backup-Datei ersetzt alle bestehenden Daten vollständig. Dies kann nicht rückgängig gemacht werden. Erstelle zuerst ein Backup der aktuellen Daten, bevor du eine alte Version wiederherstellst.
